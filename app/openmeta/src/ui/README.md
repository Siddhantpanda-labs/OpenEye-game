# UI Systems

User interface systems - HUD, menus, VR UI, in-world UI.

## Files

- `HUDRenderer.h/cpp` - HUD rendering system
- `MenuSystem.h/cpp` - Menu system (main menu, pause, settings)
- `VRUISystem.h/cpp` - VR UI menu system
- `InWorldUI.h/cpp` - In-world UI elements (screens, displays)
- `UIManager.h/cpp` - UI management and state

## Responsibilities

- Render HUD elements
- Manage menu systems
- VR UI menu interface
- In-world UI elements
- UI state management
