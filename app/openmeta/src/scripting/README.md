# Scripting Integration

Lua scripting integration for game - script bindings, script system.

## Files

- `ScriptManager.h/cpp` - Lua script management
- `ScriptBindings.h/cpp` - C++ to Lua bindings
- `GameScriptAPI.h/cpp` - Game-specific script API
- `ScriptComponent.h/cpp` - Script component for entities

## Responsibilities

- Load and execute Lua scripts
- Expose C++ functions to Lua
- Game-specific script API
- Script component system
- Hot-reload scripts in development

## Note

This will integrate with the library's scripting system.
