# Game Data

Game data structures - configurations, game data, save data.

## Files

- `GameData.h/cpp` - Game data structures
- `ConfigLoader.h/cpp` - Configuration loading
- `SaveSystem.h/cpp` - Save/load system
- `PlayerData.h/cpp` - Player data structures
- `WorldData.h/cpp` - World data structures

## Responsibilities

- Define game data structures
- Load configuration files
- Save/load game state
- Player data management
- World data management
