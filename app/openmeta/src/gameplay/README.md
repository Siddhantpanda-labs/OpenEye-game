# Gameplay Systems

Core gameplay mechanics - combat, weapons, inventory, damage, scoring.

## Files

- `CombatSystem.h/cpp` - Combat mechanics (hit detection, damage)
- `WeaponSystem.h/cpp` - Weapon framework (fire, reload, switching)
- `InventorySystem.h/cpp` - Inventory management
- `DamageSystem.h/cpp` - Damage calculation and health
- `ScoreSystem.h/cpp` - Scoring and achievements
- `GameModeManager.h/cpp` - Game mode management (arena, exploration)

## Responsibilities

- Handle all combat mechanics
- Manage weapons and inventory
- Calculate damage and health
- Track scores and achievements
- Manage different game modes
