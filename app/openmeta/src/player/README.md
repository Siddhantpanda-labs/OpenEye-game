# Player Systems

Player-specific systems - controller, movement, stats, VR support.

## Files

- `PlayerController.h/cpp` - Player movement and control
- `PlayerStats.h/cpp` - Player statistics and progression
- `VRController.h/cpp` - VR controller input and movement
- `PlayerInventory.h/cpp` - Player inventory system
- `PlayerCamera.h/cpp` - Player camera management

## Responsibilities

- Handle player input and movement
- Manage player state and stats
- VR controller integration
- Player inventory
- Camera management
