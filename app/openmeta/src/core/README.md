# Core Systems

Game core systems - application lifecycle, game loop, state management.

## Files

- `GameApplication.h/cpp` - Main game application class
- `GameLoop.h/cpp` - Game loop (update, render, fixed update)
- `GameState.h/cpp` - Game state management (menu, playing, paused)
- `GameConfig.h/cpp` - Game configuration loading

## Responsibilities

- Initialize and shutdown game systems
- Manage game loop (update/render)
- Handle game state transitions
- Load and manage game configuration
